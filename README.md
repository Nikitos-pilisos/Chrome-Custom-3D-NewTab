# Chrome-Custom-3D-NewTab
Allows you to set a custom start page in Chrome, featuring your own bookmarks and icons displayed as attractive banners. It also enables you to open local HTML files.

You can set it as your start page, but I recommend installing it as a Chrome extension via the developer menu.

Simply download all the files and point to the extension folder on your computer.

It offers plenty of settings and allows you to replace covers with images from the web or your computer.

Drag-and-drop support.
